# 改动完成即提交并推送 GitHub（项目规则，全局规定的本地落地）

> 全局规定正文：`/Users/Banner/Documents/guomengtao/docs/全局规则-改动完成即提交.md`
> 用户级全局规则：`~/.codebuddy/CODEBUDDY.md`

## 规则

**每次完成一次实质改动（代码/快应用/文档/脚本/资源），在验证通过后，立即 `commit` 并 `push` 到本仓库 GitHub 远端（SSH）。** 不攒批、不等用户再次要求、不留半成品在共享工作树里。

## 本仓库约定

- 与 EV 课程表同签名（密钥副本在 `evbox/sign/`，构建所需，**绝不入库**）
- 逐文件显式 `git add <文件>`，禁 `git add -A`
- 提交信息写清 what+why；禁 force push，回滚用 `git revert`
- 版本号按手环快应用约定 bump（同 `class-schedule` 口径）
- 改完线上相关项 push 后线上验证
