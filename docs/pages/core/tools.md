# 全部工具页（pages/tools）设计与实现

> 任务单：`evtask-D-evevbox-261114-zsd5h7`
> 关联：`docs/pages/core/index.md`（v3 首页）、`docs/pages/core/index-职责重定位分析-20261114.md`
> 版本：`1.0.73`（rpk 785,164 B）

## 1. 为什么重做

旧 `tools.ux`（648 行）把「怎么展示」做成了产品功能：图标／列表／图文三视图 + 切换条，另有设备信息、设备ID诊断、已钉页面开关、黑屏检测四行诊断混在列表尾部。问题不在花哨，在三条硬违规：

| 问题 | 旧状 | ev-six 要求 |
|---|---|---|
| 字号 | 18/20/22/24/26/28/30/32 混用 | 只准 44 / 30 / 28 / 24 四档 |
| 截断 | 7 处 `text-overflow: ellipsis` | 禁省略号，一行一意，宁可删字 |
| 条件渲染 | 3 处 `if="{{...}}"` 切整块视图 | 用 `display` 绑定，`if` 会重建节点导致列表跳位 |
| 符号 | `›` 行内箭头 + `row-divider` 分隔线 | 禁行内箭头、禁文字徽标、禁分隔线 |
| 媒体查询 | `@media (shape: capsule), (shape: pill-shaped)`（**逗号列表**） | 快应用引擎不支持逗号列表媒体查询，会导致布局全失配／整页黑屏（已在首页踩过） |

三视图还有一个隐性代价：同一份数据渲染三套模板，改一处文案要同步三处，`richTools` 与 `tools` 两份列表容易漂移。

## 2. 设计结论

**工具页只做一件事：全集入口。一行一工具，不再提供视图切换。**

```
┌────────────────────────────┐
│ [←]        工具            │  30px 标题，居中，2 字不裁
├────────────────────────────┤
│ 倒数日                      │  28px 名称
│ 纪念日倒数                  │  24px 副标题（实时优先，静态兜底）
├────────────────────────────┤
│ 农历 / 宜忌与节气           │  … 共 8 项
│ 计算器 / 四则与换算         │
│ 一言 / 每日一句             │
│ 答案 / 想问就问             │
│ 二维码 / 生成与分享         │
│ 震动 / 震动试试             │
│ 抉择 / 随机抽签             │
├────────────────────────────┤  ← 16px 留白 + 深一档底色，不画线不写字
│ 设备信息                    │
│ 设备ID诊断                  │
│ 黑屏检测                    │
└────────────────────────────┘
```

### 2.1 字号与宽度

| 元素 | 字号 | 行高 | 宽度预算 |
|---|---|---|---|
| 页标题 | 30 | 40 | 返回键 48 + 占位 48，正文区 72px → **只容得下 2 字** |
| 工具名 | 28 | 36 | 152px，最长的「二维码」3 字 = 84px |
| 副标题 | 24 | 32 | 152px，按 6.0P 计费（汉字 1.0 / 拉丁 0.55 / 空格 0.3） |

标题踩过一次坑：初版写「全部工具」4 字（120px）超出 72px 正文区，OCR 与肉眼都只看到「全部」，后两字被裁。改成「工具」2 字（60px）后稳定。**这是 ev-six「禁裁切」的直接教训：先算宽度再定文案，不是先写文案再看效果。**

### 2.2 副标题双层兜底

工具页的价值在于「不点进去也知道里面是什么」。副标题取两条路：

1. **实时摘要优先**：复用 `src/pages/index/modules/tool-summaries.js`，例如倒数日显示剩余天数；
2. **静态定位兜底**：实时接口未就绪或无数据时，用内置定位句（见 `FALLBACK`），保证首帧就有完整副标题。

两条路都过 `src/common/text-fit.js` 的 `fitSummary()`：只在标点边界截完整分句，装不下就整段不显示，**绝不硬裁出「示例：距离期」这种残句**。该模块为首页／工具页／倒数日共用，避免同一句话在不同页面一套口径。

初版实测发现 `toolSummaries.getAll` 的回调在 `onInit` 时机不稳，导致整列没有副标题、8 行全是光秃秃名称。现改为**首帧先用静态兜底填满，异步回调到了再覆盖**，两种情况都不会出现空行。

### 2.3 诊断四项的归属

- **已钉页面开关删除**：v3 首页已把钉页升级成「槽位管理」（`pages/pinned-pages` + `homepage-slots.js`），工具页再挂一个开关语义重复，且两处状态容易不同步。
- **设备信息／设备ID诊断／黑屏检测保留**：它们没有别的入口，删了就是断路。改法是不再混进工具列表，收到页尾独立一段，靠 `cardLight` 底色 + 16px 留白分组，**不写「调试」「API测试」这类灰字徽标，不画分隔线**。

## 3. 位置计费

| 区块 | 高 |
|---|---|
| 页 padding（44 top + 16 bottom） | 60 |
| 页头（返回键 40 + 12 margin） | 52 |
| 8 个工具行（有副标题 86／无 54，间距 8） | 约 640 |
| 16px 分组留白 | 16 |
| 3 个诊断行（52 + 8 间距） | 172 |
| 合计 | **约 940px** |

单屏可用 442px（490 − 48），需要滚动。这是刻意的取舍：**不压字号、不删工具，让页面滚动**。ev-six 允许滚动，禁止的是为了塞进一屏而把 24px 压到 20px。

## 4. 交互

- 工具行 `onclick="openTool($item.uri)"`，路由表与旧版一致，无新增页面。返回按钮走 `router.back()`（与旧版相同）。
- 无 `prompt.showToast`、无二次确认，点击即跳转。
