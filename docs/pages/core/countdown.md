## 1. 为什么换骨架

EvBox 老倒数日是「页面内弹层编辑器 + 裸数组存储」，被 Tom 点名为「比较老的代码」；同一个功能在 `ev/countdown`（Ev倒数日）里已经迭代了一年，功能更全、坑也踩完了。结论是**搬数据层、重排页面**，而不是在老代码上继续补。

| 能力 | 老代码 | 现在 |
|---|---|---|
| 存储 | 裸数组 `countdownDays`，无版本无迁移 | `countdownDays.v3` 版本化对象，三级回落迁移 |
| 定位 | 数组下标 | 稳定 id（`findIndexById` / `upsert` / `removeById`） |
| 计时方向 | 只有倒数 | 倒数 + 正计时（`mode: down/up`） |
| 分类 | 无 | 6 个固定色（海蓝/薄荷/暖橙/玫瑰/紫罗/金黄） |
| 进度 | 无 | 4px 细进度条（仅「一次性 + 倒数」，见 §3） |
| 演示数据 | 有（3 条带「示例」前缀） | 有（3 条短名，清空后不再塞回） |
| 重复 | 有 | **保留**（不重复/每周/每月/每年，农历每年重算下一次） |
| 钉首页 | 有 | **保留**（互斥，首页大数字只有一个来源） |
| 编辑器 | 页内弹层（叠层遮挡 + 触摸注入失效风险） | 独立 `pages/countdown-edit` |

老代码的弹层编辑器还有一个硬伤：Vela 全屏 overlay 一出现，console 触摸注入全部失效（`pit`：弹层不可自动化验证），每次改动都只能上真机点。拆成独立页面后，编辑流程可截图可点击验证。

## 2. 版式（ev-six）

### 列表页

```
[←]        倒数日            30px 标题
┌──────────────────────────┐
│▎期末考试                  │ 28px 标题（≤5.2P 硬裁，不折行）
│ 128 天后                  │ 30px 粗体数字 + 24px 单位，色=条目分类色
│ ▬▬▬▬▬▬▬░░░░░░            │ 4px 进度细条（无进度则整条不渲染）
└──────────────────────────┘
[     添加     ] [ 按时间 ]   底部 56px 双按钮
```

- **左侧 4px 竖色条**替代色块图标：竖向不占横向文案预算，一屏多条也能一眼分色。
- **方向由单位承担**：「天后」= 未来，「天前」= 过去（含正计时与已过期），不写「还有/已经」这类多占一行的引导词。
- 标题按 `textFit.clampP(title, 5.2)` 硬裁：行宽 168 − 色条 4 − 间隙 8 − 右内边距 8 = 148px，28px 汉字 1P = 28px。
- 停用（首页不显示）的条目**降为次级色**，不写「已停用」标签（ev-six 禁文字徽标）。
- 排序偏好独立 key `cd_sort_name`，不与首页设置混存。

### 编辑页（可滚动，内容约 560px）

| 行 | 交互 | 字号 |
|---|---|---|
| 名称 | 跳 `pages/chinese-input`（`return_key = cd_edit_name`） | 标签 24 / 值 28 |
| 模式 | 点一下切 倒数 ⇄ 正计时 | 24 / 28 |
| 日期 | 点一下切 公历 ⇄ 农历 | 24 / 28 |
| 年月日 | 三列 `picker`（年列 60px、月日列 44px，同 `font-size: 24`） | 24 |
| 闰月 | 仅当该农历年的闰月正是所选月时出现 | 24 / 28 |
| 预览 | 30px 数字 + 24px 单位 + 24px 日期行 | 30 / 24 |
| 重复 | 点一下轮换 不重复→每周→每月→每年 | 24 / 28 |
| 颜色 | 6 格，选中用格子淡底（Vela 的 `border-*` 分属性不可靠） | — |
| 首页显示 / 钉到首页 | 仅编辑态出现（新条目默认显示、默认不钉） | 24 / 28 |
| 保存 / 删除 | 删除两次确认，5 秒窗口 | 28 |

## 3. 三条口径决策

1. **重复条目不画进度条**。Ev倒数日 原实现用 `item.date`（首次落盘的公历日）当终点，对「每年重复」的条目可能早就是几年前，算出来恒 100% —— 那是假进度。每轮起点本身没有语义，所以直接不画。正计时同理（没有终点）。
2. **农历年与公历年共用同一组年份数字**。农历与公历年份差不超过 1，用同一列表免去换算；农历月的真源是 `monthKeys[{month,isLeap}]` 与显示串严格同下标反查 —— 闰月让「下标 = 月份 − 1」不再成立，这是唯一不能算的地方。
3. **迁移不删旧键**。`countdownDays.v3` → `.v2` → 裸数组 `countdownDays` 逐级回落，读到旧格式立刻升级落盘但不删原键：回滚安全，且旧版本误读也不会看到空列表。

## 4. 数据层 API

保留给老消费者（`sync-channel.js` / `index/modules/countdown-hero.js` / `tool-summaries.js` / `lunar-calendar.ux`）的接口一个字没改：`loadList / saveList / sortList / getHomeItem / nextOccurrence / decorateItem / decorateList`。

新增：`COLORS / colorOf / tintColor / adaptColor / normalizeColor / progressOf / statusOf / findIndexById / upsert / removeById / MODE_LABELS`。

`decorateItem` 新增展示字段：`numText`（数字或「今天」）、`unitText`（天后/天前）、`progressPct`（<0 表示不画条）、`daysColor` 由页面按主题算。
