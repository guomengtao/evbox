# 中文输入页面问题分析与优化

> 分析页面：`src/pages/chinese-input/chinese-input.ux`
> 日期：2026-09-20

---

## 一、问题总览

| # | 问题 | 严重程度 | 根因 |
|---|------|----------|------|
| 1 | 宽度未全屏 | 中 | 各屏幕形状 side padding 不一致，默认 6px 偏窄 |
| 2 | 顶部返回按钮区域浪费空间 | 中 | `.header-placeholder` 48×48 占位，胶囊屏不需要 |
| 3 | 完成按钮被遮挡 | **高** | InputMethod 组件高度（305px 胶囊）远超可用空间 |
| 4 | 光标指示为竖线 `|` | 低 | 小屏上 `|` 易被误认为 `!` |

---

## 二、详细分析

### 2.1 宽度未全屏

**当前 CSS：**

| 屏幕形状 | side padding |
|----------|-------------|
| 默认（无匹配） | `6px` 左右 |
| rect | `10px` |
| capsule/pill-shaped | `16px` |
| circle | `20px` |

默认只有 6px，看似接近全屏但不统一。rect 屏 10px 也偏窄。

**影响**：键盘按键被两侧 padding 挤压，可点击区域缩小。

---

### 2.2 顶部返回按钮区域浪费

当前 header 结构（来自 `header.css`）：

```
.header
├── .back-btn-wrapper (48×48)  ← 返回按钮
├── .header-title (flex: 1)    ← 标题居中
└── .header-placeholder (48×48) ← 空占位，用于平衡标题居中
```

胶囊屏宽度只有 ~200px，一个 48px 空占位完全没必要。可以参考 `add-course.ux` 中的做法，在胶囊屏媒体查询里把 `.header-placeholder` 归零。

---

### 2.3 完成按钮被遮挡

**这是最严重的问题。**

页面结构：

```
.page (height: 100%, flex column)
├── .header (44px + 10px margin)
├── .input-display (44px + 6px margin)
└── .keyboard-area (flex: 1, column)
    ├── .keyboard-close-row (36px, 含"完成"按钮)
    └── <input-method> (剩余空间)
```

**InputMethod 组件各屏幕高度：**

| screenType | 高度 |
|-----------|------|
| pill-shaped (胶囊) | **305px** |
| rect (方屏) | **255px** |
| circle (圆屏) | **321px** |

**胶囊屏空间计算（屏幕约 390px 高）：**

| 占用 | 高度 |
|------|------|
| `.page` padding (top+bottom) | 60px |
| `.header` (44 + 10 margin) | 54px |
| `.input-display` (44 + 6 margin) | 50px |
| `.keyboard-close-row` | 36px |
| **已占用** | **200px** |
| **剩余给键盘** | **190px** |
| **键盘实际需要** | **305px** |

**结论：键盘需要 305px，只剩 190px，溢出 115px。**

因为 `.keyboard-area` 只有 `flex: 1` 而没有 `scroll`，超出的 115px 直接被裁剪。`keyboard-close-row`（含"完成"按钮）放在该区域顶部但被键盘向下挤压，在溢出裁剪中首当其冲。

部分屏幕下可能还能看到完成按钮，但在小尺寸胶囊屏上完全被顶出可视区。

---

### 2.4 光标竖线 `|` 被误认为叹号

```html
<text class="cursor" show="{{ showCursor }}">|</text>
```

竖线 `|` 在手机上看起来是光标闪烁，但在胶囊手表屏（~200px 宽）上由于像素密度和尺寸关系，`|` 很容易被看成 `!`（叹号）。改为下划线 `_` 更直观。

---

## 三、修复方案

### 3.1 统一全屏宽度

各屏幕形状 side padding 统一为 `16px`（与胶囊屏一致），rect 从 10px 改为 16px，默认从 6px 改为 16px。

### 3.2 胶囊屏 header-placeholder 归零

```css
.header-placeholder {
  width: 0;
  height: 0;
  margin: 0;
}
```

与 `add-course.ux` 做法一致，把 48px 空间还给标题和键盘。

### 3.3 完成按钮固定可见 + 键盘可滚

把 `.keyboard-area` 从纯 flex 布局改为 scroll 包裹键盘区域：

```
.keyboard-area (flex: 1, column)
├── <scroll scroll-y="true" class="keyboard-scroll">
│   └── <input-method>
└── .keyboard-close-row (flex-shrink: 0, 完成按钮固定在底部)
```

这样：
- 键盘内容在 scroll 内可滚
- 完成按钮始终固定在可视区底部
- 不会被键盘高度顶出去

### 3.4 光标改为下划线

```html
<text class="cursor" show="{{ showCursor }}">_</text>
```
