# EvBox 胶囊屏首页美化设计（图标 / 列表 / 图文 三模式 + PNG 双图图标）

> 日期：2026-09-26
> 范围：`src/pages/index/index.ux`（首页工具区）与图标资源体系
> 尺寸依据：`doc/capsule-font-standard.md`、参考工程 `docs/胶囊屏UI规范.md`、`docs/PNG图标十色兼容分析.md`
> 第一要求：**页面精美、字号够大、点击方便**；默认**图标模式**；图片一律 **PNG 双图（dark/light）**；新增**一行模式切换**；胶囊屏图标模式**一行 2 列**。

---

## 0. 一句话方案

> 首页工具区从"汉字图标宫格"升级为**三种可切换的展示模式**（默认图标模式），图标全部换成 **PNG 双图**（`common/icons/tools/{dark,light}/`），模式选择持久化在 `homepage_settings.toolViewMode`。

| 模式 | 胶囊屏形态 | 信息量 | 适合谁 |
|------|-----------|--------|--------|
| **图标模式**（默认） | 一行 **2 列**大卡片：PNG 图标 40×40 + 名称 24px | 最低、最干净 | 想"抬手点一下就进" |
| **列表模式** | 一行一个工具：图标 28 + 名称 28px + 右侧 › | 中，扫视最快 | 工具多、要快速定位 |
| **图文模式** | 整宽卡片：图标 36 + 名称 26 + **一行动态摘要 22px** | 最高（带实时数据） | 想"不进页面就看到数据" |

## 一、量化验收（沿用项目规范，不满足即未完成）

| 维度 | 硬指标 |
|------|--------|
| 中文最小字号 | ≥22px（胶囊屏底线）；工具名 **24px**、列表名 **28px**、图文主标 **26px**、摘要 **22px** |
| 可点区域 | 图标卡片 ≥76×88px；列表行 **160×56**；图文卡片 **160×72**；模式切换段 **53×52** |
| 触控热区 | 视觉不足 52px 时外层 wrapper 上下各补 8px |
| 对齐 | 8px 栅格；卡片间距 8px（图标模式）/ 6px（列表、图文） |
| 留白 | 顶部/底部避让 30px，左右 16px（内容区 160px） |
| 字号档位 | 只用 28 / 26 / 24 / 22 四档（不允许 25、27 这类随手值） |
| 颜色 | 全部来自 `store.getTheme`；**PNG 图标色只有两档**（见第六章） |
| 禁用 | emoji（实测渲染成方框）、`transform: scale`、位移动画 |
| 图标 | **禁止自绘 path**，形状 100% 取自 Lucide 官方 SVG（项目既有铁律） |

## 二、现状问题诊断（为什么要改）

| # | 问题 | 现状证据 | 观感后果 |
|---|------|----------|----------|
| 1 | **图标是汉字** | `TOOLS` 里 `icon: "倒"/"历"/"算"/"码"/"震"/"备"/"设"`，用 `<text font-size: 40px>` 渲染 | 汉字当图标，字形复杂、粗细不一，谈不上"精美" |
| 2 | **只有一种展示形态** | `.tool-card` 固定 `width: 32%`（胶囊 47%），无任何切换 | 4 个工具还行，7 个工具就一片格子，找东西靠数 |
| 3 | **卡片比例失衡** | 卡片 `padding: 14px 2px` + 文字图标 40px 行高 48px | 上下留白多、图标小，视觉重心飘 |
| 4 | **首页不产生信息** | 工具卡片只有名字 | 抬腕只能"点进去看"，没有"扫一眼就知道"的价值 |
| 5 | **模式不可控** | 无用户偏好项 | 手大小/使用习惯不同的人，体验一刀切 |

> 本次改造同时解决 1（换 PNG）、2/5（三模式 + 一行切换）、3（重定尺寸）、4（图文摘要）。

## 三、首页信息架构与胶囊屏垂直预算

从上到下（胶囊屏 192×490，内容区 160×430）：

```
┌──────────────────────┐ y=30
│ 10:24                │ 时钟行 24px
│ 09-26 周六            │ 日期行 26px
│ ┌──────────────────┐ │
│ │  12 天  妈妈生日   │ │ 倒数日大数字 hero 56px（无数据时整行消失）
│ └──────────────────┘ │
│ [图标][列表][图文]     │ 模式切换行 52px  ← 本次新增
│ ┌───────┬──────────┐ │
│ │ 图标  │  图标     │ │ 工具区（可滚动）
│ │ 倒数日 │  农历     │ │ 图标模式 2 列
│ └───────┴──────────┘ │
│                      │
│ [  工具  ][  设置  ]  │ 底部按钮行 48px
└──────────────────────┘ y=460
```

| 区块 | 高度（胶囊屏） | 说明 |
|------|---------------|------|
| 顶部避让 | 30 | 半圆遮挡，禁放文字 |
| 时钟行 | 24 | 20px 字号 |
| 日期行 | 26 | 22px 字号 |
| 倒数日 hero | 56 | 已实现，无数据时 `if` 不渲染 |
| **模式切换行** | **52** | 新增，与内容区等宽 |
| 工具区 | **flex 余量 ≈ 164** | 可滚动 |
| 底部按钮行 | 48 | 工具 / 设置 |
| 底部避让 | 30 | — |
| 固定合计 | **266** | 工具区余量 = 430 − 266 |

> **余量偏紧的预案**（真机实测后二选一）：
> ① 把「时钟 + 日期」合并成一行（如 `10:24 · 09-26 周六`）省下 26px；
> ② 模式切换行保持 52px 不变，但把三段改为右对齐的 3 个 60px 小 chip，左侧留给当前模式名。

## 四、三种模式的详细规格（胶囊屏）

### 4.1 图标模式（默认）——一行 2 列

```
内容区 160px = 2 × 76 + 8(间距)
┌──────────────┬──────────────┐
│   ┌──────┐   │   ┌──────┐   │   卡片 76 × 88
│   │ PNG  │   │   │ PNG  │   │   图标 40 × 40（居中）
│   │ 40×40│   │   │ 40×40│   │   名称 24px，单行，居中
│   └──────┘   │   └──────┘   │   垂直：上 12 / 图标 40 / 间距 8 / 文字 32 / 下 -4
│    倒数日     │     农历      │
└──────────────┴──────────────┘
```

| 属性 | 值 |
|------|-----|
| 卡片 | 胶囊 **76 × 84（纯图标）**，圆屏 196 × 130，方屏 160 × 122；圆角 12px；底色 `theme.card` |
| 列数 | **所有屏型一律 2 列（一行 2 个）** —— 用户口径：图标模式只要一行 2 个，且要大 |
| 图标 | 胶囊 **56×56（无文字）**、方屏 **56×56**、圆屏 **64×64**（源统一 64×64，**只缩不放**） |
| 名称 | **胶囊屏不显示**（用户口径：胶囊屏图标模式去掉文字描述）；方屏 28px；圆屏 30px；单行省略 |
| 间距 | 卡片间 8px，行间 8px（胶囊 6px） |
| 按压反馈 | 底色切到 `theme.cardLight` + 短震 |
| 一屏可见 | 胶囊约 2 行（84px 卡片，滚动），每行 2 个 |

> **胶囊屏为什么敢去掉文字**：① 图标模式下工具是"扫一眼点进去"的入口，2 列大图标已足够辨识；② 模式切换行就在正上方，需要看名字时一键切到**列表模式**；③ 去掉文字后卡片从 100 → **84px**，一屏从 1.5 行变成约 2 行。

### 4.2 列表模式——一行一个工具

```
┌────────────────────────────┐
│ ┌──┐  倒数日            ›   │  行 160 × 56
│ │28│                        │  图标 28×28 放在 40×40 容器内
│ └──┘                        │  名称 28px（列表主文字档）
└────────────────────────────┘
```

| 属性 | 值 |
|------|-----|
| 行 | 160 × 56px，圆角 10px，底色 `theme.card`，行间 6px |
| 图标 | PNG 28×28（居中于 40×40 容器，左内边距 8px） |
| 名称 | **28px** / 行高 36px（胶囊"列表主文字"档） |
| 右侧 | chevron PNG 18×18（`icon_chevron_right.png`，复用双图） |
| 一屏可见 | 约 2.9 行（滚动） |

### 4.3 图文模式——图标 + 名称 + **实时摘要**

```
┌────────────────────────────┐
│ ┌────┐  妈妈生日            │  卡片 160 × 72
│ │36  │  还有 12 天 · 每年    │  图标 36 / 主标 26px / 摘要 22px
│ └────┘                     │
└────────────────────────────┘
```

| 属性 | 值 |
|------|-----|
| 卡片 | 160 × 72px，圆角 12px，底色 `theme.card`，卡片间 8px |
| 图标 | PNG 36×36（居中于 44×44 容器） |
| 主标 | 26px / 行高 34px / 单行省略 |
| 摘要 | 22px / 行高 30px / `theme.textSecondary`；高亮数字用 `theme.accent` |
| 摘要为空 | 整行不渲染（不留空行） |

**摘要数据来源（全部读现有 storage / 模块，不新造数据结构）**：

| 工具 | 摘要文案示例 | 数据来源 |
|------|-------------|----------|
| 倒数日 | `妈妈生日 · 还有 12 天` | `data/countdown.js` → `getHomeItem()` 的 `title` / `daysText`（复用首页 hero 的同一份逻辑） |
| 农历 | `八月十六 · 中秋后 354 天` | `lib/lunar.js` → `solarToLunar()` + `upcomingFestivals()` |
| 计算器 | `上次：9 × 8 = 72` | storage `calc_history` 最新一条（本次新增，已登记） |
| 二维码 | `3 个 · 最近：我的网址` | storage `qrcode_items_list` |
| 震动 | `4 个自定义方案` | storage `vibration_presets` |
| 数据备份 | `2 份 · 最近 09-25` | storage `backup_list`（条数 + 最近时间，见 `pages/backup-restore`） |
| 设备信息 | `Xiaomi · 手环 9` | `@system.device` 的 `brand` / `model`（与 `pages/device-info` 同源） |

> 摘要统一走一个 `summaries.js`（首页 `modules/` 下），按工具 id 注册取数函数；取不到就不显示——**绝不显示"未知/加载中"这类脏文案**。

### 4.4 三模式 × 三屏型对照

| 模式 | 胶囊屏（192） | 圆屏（≈480） | 方屏（336） |
|------|--------------|-------------|------------|
| 图标模式 | **2 列**，卡片 76×100，图标 48 | **2 列**，卡片 196×130，图标 64 | **2 列**，卡片 160×122，图标 56 |
| 列表模式 | 行 160×56，图标 28 | 行 408×64，图标 32，名称 30px | 行 304×60，图标 30 |
| 图文模式 | 卡片 160×72，图标 36 | 卡片 408×80，图标 44，摘要 24px | 卡片 304×76，图标 40 |

> 图标模式的列数**不随屏型变化**（一律 2 列）；变的是卡片与图标尺寸。源图 64×64 保证任何显示尺寸都是缩图。

## 五、模式切换行（本次新增）

### 5.1 位置与形态

位置固定在**倒数日 hero 之下、工具区之上**（见第三章结构图），整宽 160px，**分段控件**形态：

```
┌──────────┬──────────┬──────────┐
│   图标   │   列表   │   图文   │   每段 53 × 52，共 160
└──────────┴──────────┴──────────┘
   选中：accent 底 + bg 字（实心）     未选中：card 底 + textSecondary 字
```

| 属性 | 值 |
|------|-----|
| 容器 | 160 × 52px，圆角 26px（全圆角，呼应胶囊屏），底色 `theme.card` |
| 每段 | 53 × 52px（三档等分，`160/3 ≈ 53.3`） |
| 文字 | 24px / 行高 52px / 居中（2 字 = 48px ≤ 53 ✅） |
| 选中态 | 底 `theme.accent`、字 `theme.bg`、加粗 |
| 未选中 | 底透明、字 `theme.textSecondary` |
| 点击 | `vibrator.vibrate({mode:'short'})` + 立即重排工具区 |
| 三屏型 | 圆屏/方屏同结构，容器改为 60% 宽居中（避免过宽显得空） |

> **不用图标做切换按钮**：三个模式名只有 2 个字，文字比图标更易辨（且省 3 张图标）。

### 5.2 持久化与默认值

```js
// storage key: homepage_settings
{
  ...,
  "toolViewMode": "icon"   // "icon" | "list" | "rich"，缺省即 "icon"（默认图标模式）
}
```

- 读取：`store.getHomepageSettings()` → `settings.toolViewMode || "icon"`（**旧数据无此字段时自动落到图标模式**）
- 写入：切换即写（`store.setHomepageSettings`），与 `showTime/showPinnedBar/showCountdown` 同一套机制
- 首页设置页（`pages/homepage-settings`）：新增一行「工具显示」→ 当前模式名 + 折叠三选（与"字号""钉首页"折叠行同风格）

### 5.3 布局稳定性

- 三种模式的**卡片/行高度不同**，切换后工具区高度变化 → 保持工具区为 `flex: 1` + 独立滚动容器，切换时**不改变上方任何区块的高度**，避免整页跳动。
- 切换后用一次 `$forceUpdate()` 重排（沿用 `index.ux` 既有做法），不做过渡动画（手环上动画=掉帧）。

## 六、PNG 双图图标规范（本项目的既定做法，本次扩展到工具图标）

### 6.1 双图模式原理

```html
<!-- 外层 div 承担：主题色背景、圆角、点击热区；内层 image 承担：固定颜色的 PNG -->
<div class="tool-icon-box" style="background-color: {{ theme.cardLight }}" onclick="openTool(...)">
  <image class="tool-icon-img" src="/common/icons/tools/{{ iconTheme }}/tool_countdown.png"></image>
</div>
```

| 层 | 作用 | 能否被主题着色 |
|----|------|---------------|
| 外层 `div` | 背景、圆角、热区 | ✅ 用 `theme.*` 变量 |
| 内层 `image` | 图标形状（PNG） | ❌ **PNG 是静态图，`color` 无效** —— 所以必须靠"两套图"适配亮/暗主题 |

### 6.2 目录与命名

```
src/common/icons/
├── dark/  light/                 # 既有：导航类图标（back/chevron/plus/trash…，32×32）
└── tools/
    ├── dark/                     # 暗色主题用（8 套主题）
    │   ├── tool_countdown.png
    │   ├── tool_lunar.png
    │   ├── tool_calculator.png
    │   ├── tool_qrcode.png
    │   ├── tool_vibrate.png
    │   ├── tool_backup.png
    │   └── tool_device.png
    └── light/                    # 亮色主题用（晨光白 / 暖阳米）
        └── （同名 7 张）
```

### 6.3 尺寸、颜色与主题映射

| 项 | 值 |
|----|-----|
| 源尺寸 | **64 × 64 PNG（RGBA）**，显示尺寸一律 ≤ 源尺寸：胶囊 48 / 方屏 56 / 圆屏 64（图标模式）、36（图文）、28（列表） |
| 安全内边距 | Lucide 的 24 viewBox 自带留白，图形约占源图 83%，图标之间视觉大小一致 |
| 线宽 | 官方 `stroke-width: 2`（24 viewBox）→ 光栅化到 64px 后约 **5px** 实线，不再另行加粗 |
| `dark` 变体色 | `#ffffff`（纯白线条） |
| `light` 变体色 | `#333333`（深灰线条） |
| 主题映射 | `iconTheme = (themeName === 'light' \|\| themeName === 'warm') ? 'light' : 'dark'` |
| 覆盖主题 | `dark` → 深空蓝/翡翠绿/珊瑚红/暗夜黑/深空灰/暗紫魅影/墨绿护眼/琥珀金（8 套）；`light` → 晨光白/暖阳米（2 套） |
| 体积 | 实测 **14 张共 23KB**（64×64 源，0.6–2.8KB/张）——可忽略 |

### 6.4 生成流程（扩展现有脚本，不新增工具链）

- 现有 `_gen_lucide_icons.py` 的三步法直接复用：**下载 Lucide 官方 SVG（本地缓存）→ 替换 `stroke` 为 `#ffffff` / `#333333` → `rsvg-convert` 光栅化为 48×48 PNG**。
- 脚本新增一组 `TOOL_ICONS` 白名单（工具 id → Lucide 名称 + 输出文件名），输出到 `src/common/icons/tools/{dark,light}/`。
- **铁律**：禁止自绘 `path`（历史踩坑：抄错 path 导致图标变形），只用官方名称。

| 工具 | Lucide 名称 | 输出文件 |
|------|------------|----------|
| 倒数日 | `calendar-days` | `tool_countdown.png` |
| 农历 | `moon-star` | `tool_lunar.png` |
| 计算器 | `calculator` | `tool_calculator.png` |
| 二维码 | `qr-code` | `tool_qrcode.png` |
| 震动 | `vibrate` | `tool_vibrate.png` |
| 数据备份 | `database-backup` | `tool_backup.png` |
| 设备信息 | `watch` | `tool_device.png` |
| （模式切换 chevron） | `chevron-right` | 复用既有 `icon_chevron_right.png` |

### 6.5 ⚠️ 必须避开的"叹号"坑

参考工程实测：**20+ 个页面出现过图标显示为「!」**，根因是页面没有在 JS 里提供 `iconTheme` → 路径变成 `common/icons/tools/undefined/xxx.png` → 渲染成叹号占位。

因此首页必须：

```js
private: { iconTheme: "dark" }        // ① 给默认值，防异步返回前闪烁/报错
onInit() { store.getTheme(function(t, name) { self.theme = t; self.updateIconSrc(name) }) }
onShow() { store.getTheme(function(t, name) { self.updateIconSrc(name) }, true) }   // ② 每次进入都刷新
updateIconSrc(name) { this.iconTheme = (name === 'light' || name === 'warm') ? 'light' : 'dark' }
```

> 首页当前**尚未**加载工具类 PNG，本次改造首次引入 → 这三段代码必须齐全（`updateIconSrc` 已存在于 `index.ux`，沿用即可）。

## 八、性能与体积

| 项 | 估算 | 结论 |
|----|------|------|
| 单帧节点（图标模式） | 7 卡片 × (1 容器 + 1 图 + 1 文字) ≈ 21 | 远低于 200 红线 ✅ |
| 单帧节点（列表模式） | 7 × 4 ≈ 28 | ✅ |
| 单帧节点（图文模式） | 7 × 5 ≈ 35 | ✅ |
| 图文摘要取数 | 7 次 storage 读（可缓存，`onShow` 时刷新一次） | 建议：只在图文模式且 `onShow` 时读，避免无谓 I/O |
| 包体积 | 图标 +7KB；代码 +≈4KB | 可忽略 |
| 首屏 | 图标是静态资源，无网络等待 | 与现状一致 |
