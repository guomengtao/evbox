# 添加/编辑课程页面 - 文本显示问题分析报告

## 概述

分析 `add-course.ux`（添加课程）和 `course-manager.ux`（课程管理/编辑）两个页面的所有文本显示问题，包括：文字被行高挤压、被输入框挤压、行太宽导致文字丢失等问题。

---

## 问题分类统计

| 问题类型 | add-course.ux | course-manager.ux | 合计 |
|---------|---------------|-------------------|------|
| 缺少 line-height（默认样式） | 10 | 1 | 11 |
| 缺少 line-height（特定shape） | 0 | 10 | 10 |
| Input按钮文字被挤压 | 1 | 3 | 4 |
| 文字溢出无截断保护 | 3 | 0 | 3 |
| **总计** | **14** | **14** | **28** |

## 一、add-course.ux（添加课程页面）

### 1.1 缺少 line-height - 默认样式（10处）

默认样式未设置 `line-height`，浏览器将使用默认行高，导致文字被行高挤压或行距异常。

| # | CSS类名 | font-size | 问题描述 | 影响文本 |
|---|---------|-----------|---------|---------|
| 1 | `.step-hint` | 28px | 无 line-height | "12门" / "{{ courseName }} \| {{ courseTime }}" |
| 2 | `.card-course-name` | 36px | 无 line-height | 课程名称（如"语文"） |
| 3 | `.stepper-label` | 28px | 无 line-height | "小时"、"分钟" |
| 4 | `.stepper-val` | 40px | 无 line-height | 时间数值（08、30等） |
| 5 | `.picker-label` | 32px | 无 line-height | "开始"、"结束" |
| 6 | `.location-text` | 32px | 无 line-height | 位置文本（如"301教室"） |
| 7 | `.location-cursor` | 32px | 无 line-height | 光标 "_" |
| 8 | `.optional-hint` | 24px | 无 line-height | "选填" |
| 9 | `.course-index-hint` | 24px | 无 line-height | "1 / 12" 分页提示 |
| 10 | `.swipe-arrow` | 28px | 无 line-height | "◀"、"▶" 箭头 |

### 1.2 Input按钮文字被挤压（1处）

| # | CSS类名 | font-size | height | 问题 |
|---|---------|-----------|--------|------|
| 11 | `.stepper-btn` | 28px | 40px | 字号28px，按钮高仅40px，内部padding不足，文字紧贴边缘 |

### 1.3 文字溢出无截断保护（3处）

动态内容可能超出容器宽度，但未设置 `max-lines` / `text-overflow: ellipsis`。

| # | CSS类名 | 动态内容 | 风险 |
|---|---------|---------|------|
| 12 | `.step-hint` (step 3) | `{{ courseName }} \| {{ courseTime }}` | 长课程名+时间字符串（如"思想政治 \| 08:00 - 08:45"）可能超出屏幕宽度 |
| 13 | `.step-title` (step 2) | `时间 · {{ courseName }}` | 长课程名+"时间 · "前缀可能溢出 |
| 14 | `.confirm-value` | `{{ courseTime }}` | 时间字符串无截断 |

## 三、调整方案

### 3.1 line-height 规范

所有文本元素必须设置 `line-height`，建议值为 `font-size + 8px ~ 12px`：

| font-size | 推荐 line-height |
|-----------|-----------------|
| 20px | 28px |
| 24px | 32px |
| 28px | 38px 或 40px |
| 32px | 42px |
| 34px | 44px |
| 36px | 48px |
| 40px | 50px |

## 四、总结

- **add-course.ux** 共 **14** 处文本显示问题
- **course-manager.ux** 共 **14** 处文本显示问题
- **合计 28** 处问题
- 核心原因：大量文本元素缺少 `line-height` 导致浏览器使用默认行高，文字被挤压或显示异常
- 部分动态文本缺少 `max-lines` / `text-overflow: ellipsis` 截断保护，长内容会溢出丢失
- 个别按钮高度不足以容纳字号，文字紧贴边缘

按照上述方案逐项调整后，可解决所有文本显示问题。
