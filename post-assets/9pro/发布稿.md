## 六、发布前必须解决：包怎么给

米坛资源有两种版本模式，EvBox 现在**两种都走不通**，这是唯一阻塞项：

| 模式 | 要求 | 现状 |
|---|---|---|
| `external` 外链 | 需一个**公网无需登录即可下载**的直链 | `guomengtao/evbox` 是 **private**，Release 直链对外 404；且仓库**还没有任何 Release** |
| `local` 附件 | 需通过 `/attachments/upload` 拿到 hash | 这条链路在米坛尚未打通（发更新楼时已验证：文件入库但服务端不回 hash） |

对比参照：Ev课程表能发，是因为 `guomengtao/class-schedule` 是 **public**，外链指向 `releases/download/vX/xxx.rpk` 任何人可下。

**三条解法，按推荐度排序：**

1. **把 `guomengtao/evbox` 转为 public，打一个 v1.0.57 Release 上传 rpk**（最干净，与 class-schedule 完全同构，之后所有更新都能自动发）
   - 命令已备好：`gh repo edit guomengtao/evbox --visibility public --accept-visibility-change-consequences` → `gh release create v1.0.57 dist/*.rpk`
   - 需要你确认：这个仓库里有没有不愿公开的内容（`scripts/` 下有大量调试脚本，建议先加 `.gitignore` 或清理）
2. **手工在浏览器建帖并传附件**（一次性），拿到资源 ID 后，以后更新走「外链」也需要第 1 条
3. **继续攻附件上传**（技术上未通，不建议现在卡在这里）

首发成功后，把这条发布位登记进 `ev-publisher/core/products.json`，格式与现有 13 位一致：

```json

  "id": "bb-<新资源ID>",
  "platform": "bandbbs",
  "platformName": "米坛社区",
  "device": "手环9 Pro 方屏",
  "resourceId": <新资源ID>,
  "url": "https://www.bandbbs.cn/resources/<新资源ID>/",
  "channel": "eb-9p-r",
  "mode": "resource",
  "note": "EvBox 首发 · 分类 100 小米手环9 Pro"
}
```

同时 `core/channels.json` 要新增 EvBox 的渠道码（建议 `eb-` 前缀与 Ev课程表 的 `t-`/`q`/`g` 区分）。
这属于第二阶段的事——**当前发布器只支持「更新已有资源」，不支持「新建资源」**，首发这一帖必须人工建，或者另做「建帖」能力。
